# 📦 Warehouse Management System (Manager & Employee Panel)

A full-stack **Warehouse Management System** built using the **MERN Stack**.
This application helps manage warehouse products, stock, billing, and employee operations with separate **Manager** and **Employee** panels.

---

# 🚀 Features

## 👨‍💼 Manager Panel

* Manager Login / Authentication
* Add New Products
* Update Product Details
* Delete Products
* Manage Stock
* View All Products
* Manage Employees
* Dashboard with product statistics

## 👷 Employee Panel

* Employee Login
* View Products
* Add Products to Order
* Billing System
* Billing History
* Warehouse Dashboard
* Profile Management

---

# 📊 Dashboard Features

* Total Products Count
* Total Stock Available

# ⚙️ Installation

Clone the repository

```
git clone https://github.com/your-username/warehouse-management-system.git
```

Install backend dependencies

```
npm install
```

Install frontend dependencies

```
npm install
```

Run Backend

```
npm run server
```

Run Frontend

```
npm run dev
```

---

# 🌐 Environment Variables

Create a `.env` file and add:

```
PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
```
